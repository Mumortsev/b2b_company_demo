# ПОТОК ИНЖИНИРИНГ

Русскоязычный демонстрационный сайт вымышленного производителя конвейерных систем. Основа — [Fabrica](https://github.com/akajdid-mostafa/fabrica), исходная композиция, сетки и анимации сохранены. Адаптация контента и функциональности — Mumortsev.

## Запуск

Node.js 22, npm:

```sh
npm ci
npm run dev
```

Локальный адрес: http://localhost:5173/b2b_company_demo/

```sh
npm run build
npm run preview -- --host 0.0.0.0
```

Сборка — `dist/`. Workflow `.github/workflows/pages.yml` публикует её на GitHub Pages: https://mumortsev.github.io/b2b_company_demo/

## Содержание

11 страниц: главная, компания, услуги, каталог, концепции, журнал, статья, технический запрос, FAQ, конфиденциальность, 404.

Каталог включает восемь демонстрационных моделей в шести направлениях, фильтры с состоянием в URL и подробности моделей. Четыре концепции раскрываются в диалогах. В журнале — восемь самостоятельных материалов. Форма сохраняет технический запрос в TXT на устройстве; данные не отправляются и не сохраняются сервером. Телефоны, реквизиты и отзывы реальной компании не выдумывались.

## Изменение контента

- `src/assets/js/potok-data.json` — модели оборудования, концепции и статьи. Данные используются для подробностей, статей и формы. При изменении ассортимента также обновите соответствующие статические карточки в `src/products.html` и `src/index.html`.
- `src/*.html` — страницы и статические тексты.
- `src/partials/` — общие меню, подвал, метаданные.
- `src/assets/css/_potok.css` — палитра, шрифты и состояния добавленных компонентов.
- `src/assets/js/potok.js` — фильтры, подробности, статьи, формирование файла.
- `src/assets/docs/potok-guide.pdf` — памятка для подготовки запроса.
- `SITE_BASE_PATH` — базовый путь сборки, по умолчанию `/b2b_company_demo/`. При переименовании репозитория измените его в `vite.config.js` и `scripts/prepare-pages.mjs`, а также URL Open Graph в `src/partials/title-meta.html`.

Для реальной отправки заявки требуется серверный обработчик с валидацией и защитой от спама. До его подключения сайт не показывает успешную отправку.
